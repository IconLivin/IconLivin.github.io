# Knesset Slots

Сатирическая слот-машина к выборам в Кнессет 27 октября 2026 года. Крутишь
барабаны с портретами глав партий, собираешь пять в ряд — машина объявляет, за
кого ты проголосуешь. Денег, ставок и мандатов внутри нет.

Игра одностраничная, без сборки и без зависимостей: открывается двойным кликом,
работает офлайн, публикуется на GitHub Pages.

**Дисклеймер.** Это сатира. Не агитация, не опрос и не рекомендация, как
голосовать. Шансы подкручены ради смеха — см. [ADR 0001](docs/adr/0001-podkruchennye-shansy.md).

## Запуск

```bash
python3 -m http.server 8765   # из корня репозитория
# http://127.0.0.1:8765/
```

`file://` тоже работает, но тогда не будет `navigator.clipboard` и Web Share —
останутся скачивание карточки и копирование через fallback.

## Механика

- Окно 5×3, одиннадцать партий и джокер-бюллетень (`פתק`), который заменяет
  любой символ.
- Пять линий: три горизонтали и две диагонали (V и Λ).
- Выигрыш на линии — все пять символов одной партии (джокер считается за
  любого). Линия из пяти джокеров — «пустой бюллетень».
- Каждый выигрыш переписывает вердикт «Твой голос — X».
- Частота выигрыша — примерно 1 к 18; проверяется симуляцией:

```bash
node -e '
const E=require("./js/engine.js");
const ids=["likud","yashar","byachad","democrats","joint","otzma","shas","rzp","utj","beiteinu","raam","joker"];
let w=0; for(let i=1;i<=200000;i++) if(E.generate("s",i,ids).wins.length) w++;
console.log("1/"+ (200000/w).toFixed(1));'
```

## Воспроизводимость

Прокрут определяется парой `seed + номер`, а не состоянием браузера: ссылка
`?s=<seed>&i=<spin>` открывает ровно тот же расклад. Seed и номер прокрута
видны в интерфейсе и на карточке, поэтому результат можно проверить.

## Портреты

```bash
python3 -m venv .venv
.venv/bin/pip install "rembg[cpu,cli]" pillow opencv-python-headless
REMBG=.venv/bin/rembg ./scripts/build_portraits.sh
```

Конвейер: скачать оригиналы с Викисклада (`scripts/sources.txt`) → кадрировать
по лицу (YuNet, `scripts/crop_by_face.py`) → вырезать фон (BiRefNet-portrait) →
512×512 webp. Лицо приводится к одному масштабу и одному отступу от макушки,
поэтому в сетке все головы одного размера.

## Публикация

Сайт лежит в репозитории `IconLivin.github.io` — это user site, поэтому он
открывается с корня: <https://iconlivin.github.io/>.

Сборки нет, Pages раздаёт ветку `main` как есть:

```bash
git push origin main
```

Если Pages почему-то выключились:

```bash
gh api -X PUT repos/IconLivin/IconLivin.github.io/pages \
  -f build_type=legacy -f 'source[branch]=main' -f 'source[path]=/'
```
